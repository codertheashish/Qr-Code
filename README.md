# 📷 QR Code Generator

A simple and fast Python-based QR Code generator where you can paste any link directly into the terminal, and it automatically generate a QR image for you.


## 🚀 Features

* 📥 Paste URL directly in terminal
* 🔗 Supports Google Drive links, website URLs, images, videos, etc.
* 🖼 Generates high-quality QR code
* 💾 Saves output as `generated_qr.png`
* ⚡ Lightweight and beginner-friendly

---

## 🛠 Tech Stack

* **Python 3.x**
* **qrcode** library

---

## 📦 Installation

1️⃣ Install the required module:

```bash
pip install qrcode
```

2️⃣ Download the script from your project folder.

3️⃣Clone the project:

```bash
https://github.com/codertheashish/Qr_code.git
```

---

## ▶️ How to Use

1. Run the script:

```bash
python qr_generator.py
```

2. You will see a message:

```
Paste URL here:
```

3. Paste your Google Drive link or any URL
4. Press **Enter**
5. A QR image will be created automatically as:

```
generated_qr.png
```

---

## 📁 Output

* ✔ QR Code image
* ✔ Saved locally as `generated_qr.png`

---

## 📌 Notes

* For Google Drive links:
  Make sure you **remove “Restricted”** and set sharing to **Anyone with the link → Viewer**.
* Works fine on Windows, macOS, and Linux.
